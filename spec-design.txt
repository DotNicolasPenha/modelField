Aurelius Design System (ADS) v2.0
Human-Centered Minimal Interface System

Uma linguagem visual para aplicações desktop e web focadas em produtividade, inteligência artificial e ferramentas profissionais.

1. Filosofia
O design deve desaparecer.

A interface não deve competir com o usuário.

Ela deve funcionar como uma extensão natural do pensamento e do trabalho.

O usuário deve sentir:

clareza;
controle;
velocidade;
confiança;
tranquilidade.

A interface não deve parecer uma página web.

Ela deve parecer um software instalado no computador.

2. Princípios Fundamentais
Quiet Interface

A interface deve ser silenciosa.

Evitar elementos visuais sem função.

Não adicionar componentes apenas para preencher espaço.

Content Before Chrome

O conteúdo é o produto.

A interface é apenas o ambiente.

Prioridade:

Conteúdo

↓

Ações

↓

Navegação

↓

Decoração

Decoração deve ser praticamente inexistente.

Spatial Design

O espaço vazio é um componente.

Separações devem acontecer principalmente através de:

distância;
alinhamento;
ritmo visual.

Não através de:

bordas;
caixas;
sombras.
Human Precision

Precisão técnica com sensação humana.

A interface deve parecer:

profissional;
acessível;
amigável.

Nunca:

fria;
robótica;
corporativa demais.
Invisible Hierarchy

A hierarquia deve ser percebida naturalmente.

Usar:

tamanho;
peso;
espaçamento.

Evitar:

cores extras;
caixas;
divisores excessivos.
Motion With Purpose

Movimento deve explicar uma mudança.

Nunca deve chamar atenção.

3. Personalidade Visual

Imagine um aplicativo usado por 8 horas todos os dias.

Ele deve transmitir:

Deve parecer:
premium;
calmo;
preciso;
confiável;
organizado.
Nunca parecer:
jogo;
dashboard SaaS genérico;
aplicativo chamativo;
interface experimental.

Princípio Final

O objetivo não é criar uma interface que impressione no primeiro segundo.

O objetivo é criar uma interface que continue parecendo excelente depois de milhares de horas de uso.

Aurelius não tenta chamar atenção.

Ele cria um ambiente onde o usuário consegue pensar, criar e trabalhar sem fricção.
